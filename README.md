# Bruine

Application web de **gamification Steam** projet CNAM (GLG204).

Un joueur se connecte avec son compte Steam, gagne des points, tire des cartes, les échange sur un marché entre joueurs,
compose un deck affichable en widget sur un site externe, et convertit ses cartes en expérience.
